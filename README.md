## Description

A standalone, single-line comedy entry under 200 characters about who truly has a financial stake in your survival until the first of the month—using misdirection between personal emergency contacts and monthly rent.

## Run it

The grader runs the program on Node 22 with no network access and reads `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`):

```sh
node main.ts
```
